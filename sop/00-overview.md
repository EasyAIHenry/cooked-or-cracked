# SOP 00: overview

One episode = one claim, tested, with a verdict. Time budget: de-myth 1 h, screen 30 min, talking head 10 min, edit 1 h, guide 20 min, post, retro after 48 h.

| Step | File | Owner | Output |
|---|---|---|---|
| 1 Subject | 01-subject.md | Claude (lead scout) + Henry picks | episode folder |
| 2 Audit | 02-audit.md | Claude (creator-audit) | audit report, baseline |
| 3 De-myth | 03-de-myth.md | Claude writes, Henry tests 1 h | de-myth sheet, scorecard |
| 4 Record | 04-record.md | Henry, 30 min screen + 10 min face | raw footage |
| 5 Script | 05-script.md | Claude drafts, Henry edits on set | beat sheet + supers |
| 6 Edit | 06-edit.md | Claude in ChatCut (henry-scrapbook-reel), Henry approves each pass | UPLOAD-THIS cut |
| 7 Publish | 07-publish.md | Claude drafts captions + guide, Henry posts | captions, PDF, pinned comment |
| 8 Retro | 08-retro.md | Henry sends insights, Claude writes retro + updates skill | learning log entry |

Writing rules apply to everything: `skills/cooked-or-cracked/references/writing-rules.md`.
