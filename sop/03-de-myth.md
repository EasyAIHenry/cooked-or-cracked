# SOP 03: de-myth in one hour
Claude writes `06_research/de-myth-sheet.md` (20 min): each claim as a row (what he says, what it actually is with the source and date, install or access line, cost), pass and fail written before the test, a timed plan that fits 60 minutes with one prompt reused across variants, and gotchas flagged as untested.

Henry tests (60 min) with the timer on screen. He fills the scorecard in the script. Verdicts are written after the test, never before.

Rule: if a step fails because of Henry's setup, it is "my setup" on camera and scores meh, not cooked.
