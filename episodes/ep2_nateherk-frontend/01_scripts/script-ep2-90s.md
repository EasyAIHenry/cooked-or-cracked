# Ep2, 90-second script: install his 5, build my page, one change each

~230 words at your pace = 1:25 to 1:30. Say the number when it is on screen. Fill [brackets] after the test. The "one change" lines are drafts from the docs; keep the ones that match what you saw.

The test prompt (international, same prompt every time):
```
Build a one-page landing site for an AI screen-recording app called Snapcut. Hero with one line, three features, pricing with a free plan and a $12 plan, one sign-up button. Single index.html, no framework.
```

---

**0:00 Hook** (you, Nate's reel muted low-left)
Five free tools that turn Claude into a designer. I installed all five, then built my own page with them. [N] are worth it.

**0:05** (sting under the tally popping)

**0:07 Install** (screen: the five GitHub pages, one after another, then the terminal)
Here they are. Taste. Impeccable. Playwright CLI. Awesome Design. And the last one is not "Image twenty-three". It is img2threejs. Five lines, [N] minutes.

**0:18 Tool 1, Taste**
Same prompt, plain Claude, then Taste. [What changed in one sentence, e.g. "Font changed, layout stopped being three cards in a row."]
One thing I would change: v2 is marked experimental. Pin v1 if the page comes out weird.

**0:30 Tool 2, Impeccable**
Impeccable has 24 commands. I ran init, then polish. [What it fixed.]
One thing I would change: run init before anything else, or it guesses what your product is.

**0:42 Tool 3, Playwright CLI**
I broke the sign-up button on purpose. Playwright [found it / missed it] in [N] seconds.
One thing I would change: add "headed" so you watch the browser. Headless, you learn nothing.

**0:52 Tool 4, Awesome Design**
One file in the folder, the Linear design system. I said nothing. The page came out [looking like Linear / the same].
One thing I would change: pick a brand in your category. Apple's file on a SaaS page looks wrong.

**1:02 Tool 5, img2threejs**
His demo was a bike. Mine was [object]. [N] minutes, [$x] in tokens, and it looks like [this].
One thing I would change: plain background photo, one object, and set a 15-minute limit.

**1:14 My page** (screen: the Snapcut page built with the keepers)
This is my page with the [N] that worked. [One line: what it looks like or what it cost.]

**1:20 Verdict** (scoreboard tick, verdict stamp)
[N] out of five. [Cooked / Cracked]. [Score] out of ten. Free tools, not free tokens.

**1:25 CTA** (save frame held, then comment stamp)
Screenshot this. Comment DESIGN and I send you the install lines, the prompt and my page.

---

## Cuts if you run long
Drop the "one thing I would change" on tools 3 and 4 first. Then shorten the install beat to "Five lines. [N] minutes."

## Supers, in order
Tally (0:01) → jingle title (0:05) → terminal strip x5 (0:07) → tool cards 1 to 5 with tick/cross and the "one change" as the card's Kalam label → before/after wipe on tools 1 and 4 → time stamps on 3 and 5 → "MY PAGE" paper stamp at 1:14 → scoreboard tick + verdict at 1:20 → save frame + "comment DESIGN" at 1:25.
