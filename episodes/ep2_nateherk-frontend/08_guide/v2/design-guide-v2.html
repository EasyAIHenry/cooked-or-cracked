why this guide

Five free repos, tested on one real design job

A creator shared five free repos that are meant to turn Claude into a designer. This guide puts all five through a real job and shows what each one does, so you know which to install and when.

design tip

The small caps label above the headline is a common AI habit. Worth a look.

"Menu card text touches the edge." Measured with Playwright: 28px of space on a phone. Fine.

img2threejs

Give Claude one photo of an object. It rebuilds the object as a 3D model, in code.

free · Python 3.10+github.com/img2threejs/img2threejsbuilt the cone in 3D
pass 1: failed · only the rim showed
pass 2: photo on the left, 3D model on the right

Input: the empty cone photo. Pass 2 is a real 3D cone you can spin. It still looks like a model, not like food.

type in Claude

Check my Python is 3.10 or newer. Then install img2threejs from github.com/img2threejs/img2threejs into this project's .claude/skills folder.

then attach a photo and type

/img2threejs Rebuild this object as a Three.js model, keep the proportions, angles, and colours.

good to knowIt is strict. Its checklist has 23 steps before the first model is signed off, and it checks the photo first. Each pass gets compared with the photo, so a bad pass gets caught.
use it for

Hard objects a customer would spin round: a sneaker, a bottle, a speaker. For food, use a photo.

What you seeWhat to do
setting up
Claude answers without checking HiggsfieldSettings, Connectors, disconnect Higgsfield, connect again. Start a new chat and say "use Higgsfield".
"command not found: npx" or "node""Install Node LTS for me." Then start a new session.
A repo does not show upStart a new session in the same folder. Ask "Which skills do you have loaded?"
Impeccable: "Download failed: HTTP 404""Copy the impeccable skill from github.com/pbakaus/impeccable (.claude/skills/impeccable) into this project's .claude/skills folder."
"/impeccable" is not a commandIt went into another folder. "Run npx impeccable install --providers=claude --scope=project in this folder."
img2threejs fails straight awayPython is too old. "Update Python to 3.12 for me."
