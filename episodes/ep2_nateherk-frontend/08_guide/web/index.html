The episode, written down

A website for a shop that has none.

Two prompts, five free design tools, one Higgsfield run. Scroll, and you pipe the ice cream.

Everything started as two lines I typed.

Prompt 1, in Claude CodeDesign a 3D scroll website for a local business that does not have a website, so I can promote their service and menu. Take the style from their look and logo. It has to feel like a two to three million dollar site, and say what they sell in a few words. Give me 5 businesses in Singapore to choose from.
Prompt 2, once the first version existedUpgrade the cone visuals with Higgsfield. Keep the tone and the fonts. Separately, design a scan-and-order menu page for the QR code on the table.

Step 1

Find a shop with no website.

Claude searched Google Maps, dropped the ones that already had a site and gave me five. I picked Pompette, a soft-serve counter in Beauty World Centre. 4.9 stars from 378 reviews, and an "Add website" link where a website should be.

  • 4.5 stars or better, 150 reviews or more.
  • No website. Check Maps and a web search.
  • One product that fits in a single frame.
  • A logo with two clear colours. That is the palette.

Step 2

Install the five.

Five lines in the terminal. All free. Taste is the one that changes the very first page.

Taste

Design rules Claude reads before it writes a page. Bans the usual AI look.

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"github.com/Leonxlnx/taste-skill

Impeccable

24 commands for a page that exists: audit, critique, polish, typeset.

npx impeccable installgithub.com/pbakaus/impeccable

Playwright CLI

Claude opens your page in a real browser, clicks through it, takes screenshots.

npm install -g @playwright/cli@latest && playwright-cli install --skills -ggithub.com/microsoft/playwright-cli

Awesome Design

73 DESIGN.md files from real sites. Drop one in the folder and Claude follows it.

curl -o DESIGN.md https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md/linear.app/DESIGN.mdgithub.com/VoltAgent/awesome-design-md

img2threejs

One photo to a Three.js model, in code. Not "image twenty-three". Python 3.10 or newer.

git clone https://github.com/img2threejs/img2threejs.git ~/.claude/skills/img2threejsgithub.com/img2threejs/img2threejs

Step 3 and 4

The tools got the layout right. The cone was a cartoon.

Version one already had the final layout, the logo's teal and gold, the menu and the directions. The cone was built out of code. Design tools decide where things go and what they are set in. They cannot take a photograph. So the second prompt sent the product to Higgsfield.

Step 5 to 7

Seven sections, then a menu for the table.

The clip you scrubbed at the top is the same trick the site uses: pin the section, and move the playhead with the scroll. Then the flavours crossfade, the menu shows real prices, and the last section gets you to a hidden counter.

Step 8

Where I stopped: 60% done.

  • Ask the owner. Name, logo, the maker photo, the menu.
  • Real prices and toppings. Mine are from a March 2026 review.
  • A cup render for every flavour. Six images, 16.5 credits.
  • Topping photos for the order sheet.
  • Connect orders to a sheet, Supabase or WhatsApp. Then a domain.
  • Polish pass with Impeccable, test pass with Playwright.
