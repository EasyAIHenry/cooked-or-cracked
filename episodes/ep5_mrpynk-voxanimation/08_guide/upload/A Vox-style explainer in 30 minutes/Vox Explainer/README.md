# Vox Explainer

Henry Chua's guided skill for narrated, Vox-style explainer videos, tested
on 30 September 2026 and handed out with the guide "A Vox-style explainer
in 30 minutes".

Make a narrated, Vox-style explainer video with Claude Code.

1. Open this folder in the Claude app's Code tab (Local, Select folder).
2. Say **"install the vox-explainer skill from this folder into my personal
   Claude skills"**, then make a folder for your videos, select it, and type
   **/vox-explainer**. Or just say **"let's make a video"** in this folder.
3. Follow the guided steps — Claude writes everything, you run a handful
   of prompts in your own generator, Claude cuts the final video.

New here? Read **EXPLAINER.md** — one page, tells you everything.
