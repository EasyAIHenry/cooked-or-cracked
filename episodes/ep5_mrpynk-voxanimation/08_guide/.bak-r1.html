how it works

One skill, six clips, one finished video

A skill is a set of instructions Claude follows. This one researches your topic, writes six narration lines, one image prompt that fixes the look, and one video prompt per 10 second scene. Your generator makes the image and the six clips. Claude records the narrator with a free voice tool and joins clips and voice into one MP4. Six scenes of 10 seconds make a 60 second video.

set up once, about 20 minutes the first time
1

Two accounts. Claude Pro, US$20 a month at claude.com/pricing; Pro is enough. A Higgsfield plan that includes Seedance 2.5 at higgsfield.ai/pricing; the test used Ultimate, US$39 a month paid yearly.

2

Get the skill. Comment PYNK on @mr.pynk's reel. His page sends a DM with a link to a page that holds the download. Save the zip and double-click it. You get a folder called Vox Animations.

3

Open the Code tab. Install the Claude app from claude.com/download and sign in. In Finder make a new folder called my-videos. In the app click Code at the top centre, choose Local, click Select folder and pick my-videos.

4

Install the skill. Drag the Vox Animations folder into the chat box and type: install this skill for me. Claude copies it into its skills folder and asks before each step; click Allow.

5

Start it. Type /vox-animation. The skill checks for ffmpeg (cuts the video) and edge-tts (the free voices). Both are free; type install if it asks, and type your Mac password if macOS asks once.

6

Optional connector. So Claude can run the Higgsfield prompts for you: in the Claude app open Settings, Connectors, Add custom connector, paste https://mcp.higgsfield.ai/mcp, and sign in to Higgsfield in the browser window that opens. Without it, you paste each prompt into higgsfield.ai yourself and drag the finished files into the project folder.

1

The ask: say the topic, the arc and the voice

2 minutes

Type what you want as if briefing an editor: the subject, where the story should start and end, and the kind of narrator. Ask for three topics if you have none. The skill comes back with a one-line angle and six script lines, each with a checkable fact. Read them out loud once and ask for a change where a line runs long.

the example "Research the most controversial unsolved mystery cases in the world. Give me three topics. From the beginning to the cliffhanger, and end on the part people might never find out. A narrator that fits the mystery feel." It offered D.B. Cooper, the comet 3I/ATLAS and Amelia Earhart.
receipt Six lines, 112 words, every date and number cross-checked against two sources before the script came back.
2

One image locks the look

3 minutes

The skill writes one image prompt in its paper diorama style and offers three looks. Make one as a 9:16 image: with the connector, say generate the lagoon key and Claude does it (Nano Banana Pro, 2 credits). Without it, open higgsfield.ai, choose Nano Banana Pro, set 9:16, paste the prompt, download the image and drag it into the project folder. That picture is attached to every clip prompt, so six clips come out as one film. Pick the look that matches the mood of your ending.

Six clips at 720p, and what they cost

15 minutes

One prompt per scene: Seedance 2.5, 10 seconds, 9:16, sound on, style image attached. Choose the resolution before you start, because it sets the whole bill; 720p is enough for a phone screen. With the connector, say generate scenes 1 to 3, then 4 to 6: five at once gets a rate limit. Without it, paste each prompt into Seedance 2.5 on higgsfield.ai with the same settings and the style image, download each clip and drag it into the clips folder of your project. If Higgsfield answers with a preset suggestion instead of a video, say no and send the same prompt again. Check the six clips as a set, then move on.

4

A free narrator

2 minutes

The skill reads line one in three voices made by edge-tts, a free Microsoft text-to-speech tool that runs on your computer. It saves the three samples in the project folder; play them and reply with the name you want. It then records all six lines. A British male voice (Ryan) fit the mystery tone. If a line comes back shorter than its clip, ask for two more words rather than a slower read.

5

Claude stitches it

3 minutes

Drop the six clips into the project folder and say stitch it. The skill's script joins clip and line scene by scene, starts each voice line a quarter second in, keeps the clip's own sound low underneath, and writes final.mp4 (1080 by 1920, the Reels size) into the project folder. Two things before you post: ask Claude to normalise the loudness to minus 14 LUFS (the first output is quiet), then AirDrop or message the file to your phone and watch it once with the sound on.

receipt 60 seconds, six scenes, 30 minutes from the first prompt to final.mp4. There is no prompt pack to copy: the skill writes the script, the style prompt and the six clip prompts for your topic.

The six scenes of the finished video. One style image kept them in one look; the burnt-orange thread runs through every scene because the script asked for it.

If this happens

presetHiggsfield returns a preset suggestion instead of a clip. Decline it and send the same prompt again.
429A rate limit after five clips at once. Send three, wait for them, send three.
short lineA narration line shorter than its clip leaves dead air. Ask for two more words, not a slower read.
quietThe first final.mp4 plays low. Ask Claude to normalise it to minus 14 LUFS before you post.
textGenerated clips misspell words. Keep numbers and names in the narration and the captions, not in the picture.
1080pOnly worth the extra US$9 if the video goes to a TV or YouTube. A phone screen cannot tell.

Who this is for, and who it is not for

use it if

You want an explainer, a history short or a product story with a narrator, one look and a clean cut, and you can spend about US$14 a video on a generator you already pay for. Swap in any topic.

skip it if

You need your own face, real footage or a brand's exact logo in the shots. Generated clips drift on text and faces. You want it free: the skill is free, the clips are not.
