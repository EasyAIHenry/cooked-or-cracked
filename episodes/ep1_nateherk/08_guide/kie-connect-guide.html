before you start

Why I wrote this down

I watched a creator generate video from Claude for cents and my first reaction was that it could not be that cheap. So I paid for it myself, ran the same tests three times, and built the price table you saw in the episode. This guide is the part I could not fit into 90 seconds.

It is for people who already know how to prompt. If you are new to AI video, a platform like Higgsfield gives you templates, presets and a visual editor, and you should start there. If you know what you want and you are tired of paying a subscription for it, keep reading.

3

Create your API key

Open kie.ai/api-key and click Create New Key. Name it something you will recognise later, for example claude-code. Copy the key straight away. Kie shows the full key once; after that you only see the first few characters.

Create New Key lives here

The page asks you to sign in before it shows your keys. The blue button top right is the one you want.

What I do with the key

I paste it into one file (next step) and close the tab. If I ever suspect it has leaked, I come back to this page, delete the key and make a new one. It takes ten seconds and costs nothing. Rotating a key is normal hygiene, not a sign you did something wrong.

4

Install the Generate skill

A skill is a small folder of instructions Claude Code can read. This one, published openly by Blotato on GitHub, turns a plain sentence into a request to Kie. Open Terminal and paste these three lines one at a time.

# 1. download the skills repo
git clone https://github.com/Blotato-Inc/blotato-skills

# 2. copy just the generate skill into Claude's skills folder
cp -r blotato-skills/blotato/skills/generate ~/.claude/skills/generate

# 3. create the settings file you will put your key in
cp ~/.claude/skills/generate/.env.example ~/.claude/skills/generate/.env

Now open ~/.claude/skills/generate/.env in any text editor and paste your key after KIE_API_KEY=. Save. That file is the only place the key lives.

this is the folder you are copying
Read this before you install any skill from the internet. I ran this one through a security scanner before touching it. It flagged the skill, and it was right to: the skill reads your key from that .env file and sends requests to api.kie.ai. That is exactly its job, so I was comfortable installing it. The habit to keep is this: open the files, check the key is read from a file you control, and check the requests only go to the provider you expect. If you cannot verify those two things, do not install it.

Run your first generation

Restart Claude Code so it picks up the new skill, then type the line below. The skill works out which model fits, quotes the price in credits, and waits for you to say go. Nothing is charged until you do.

/generate a still: matte black skincare serum bottle on wet slate, morning light, no text
what you should see

A short reply like "Nano Banana 2, 8 credits, about $0.04. Go?" Type go. Thirty seconds later the image lands in your generations folder with a small text file next to it that records the prompt, the model and the cost. Every generation gets one, so you always know what a shot cost you.

Two more worth trying: a poster with words on it (/generate a still with a poster that reads COOKED OR CRACKED, bold red stamp style), which should switch to GPT Image 2 because it is better at text. Then a video from your still (/generate animate the last still, 5 seconds, spend cap $1). The spend cap is the habit that keeps this cheap.

the honest bit

Who this is for, and who it is not for

use Kie + Claude if

You already write good prompts. You care about the price per image and per clip. You are fine working from a line of text rather than a canvas. You want to stop paying for credits you do not use.

stay on a platform if

You are new to AI video. You want presets, a visual editor, and plugins for After Effects and Premiere. You will pay more per generation, and you will get a starting ground. That is a fair trade when you are learning.

Where I landed

For images and cheaper clips, Kie beats both Higgsfield's website and its API. The API narrows the gap on video and is the right call if you are building a product on Higgsfield's model set. I run my own month, about 40 images and 16 short clips, on Kie for around eleven dollars. The full table with every number linked to its source is the second file in this folder.
